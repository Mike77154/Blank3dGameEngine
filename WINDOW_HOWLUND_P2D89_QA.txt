Blank3D v3.27.3 - HOWM89 / WindowsWindow89 / Primitive2DDatabase89 QA
=====================================================================

Release intent
--------------
1. GenWinConfigC89 remains the native-window state/config authority.
2. GenWinConfigC89 must not know that HOWM89/Howlund exists.
3. A reusable adapter translates the gwc89_provider contract into HOWM89.
4. Blank3D's former direct Win32 native-window creator is isolated as the
   optional HOWM89 backend WindowsWindow89.
5. Blank3D keeps only the native HWND/HDC renderer-interoperability bridge.
6. Primitive2DDatabase89 v0.4.0 encyclopedic is vendored byte-for-byte first;
   no HUD/crosshair/editor migration is performed in this release.

Native window authority
-----------------------
Blank3D/GameVerbs/GeneralConfig.cfg
        -> GenWinConfigC89
        -> gwc89_provider
        -> HOWM89 <-> GenWinConfigC89 adapter
        -> Howlund Window Maker 89
        -> WindowsWindow89
        -> Win32
