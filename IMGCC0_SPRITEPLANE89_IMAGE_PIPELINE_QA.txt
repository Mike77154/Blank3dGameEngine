Architecture checks
-------------------
- imgcc0 is the file decoder; it owns no renderer.
- SpritePlane89 is generic world-plane/billboard geometry; it owns no image decoder.
- Weapon muzzle image is a temporary SpritePlane89 client of the existing muzzle event.
- HUD/BigHUD use the optional image provider; vector primitives remain unchanged.
- GCrosshair89 retains vector/image/hybrid modes.
- GScope89 retains vector commands and now routes raster GSP89_CMD_SPRITE through the HUD image provider.
- SpritePlane89 lower-case API is namespaced sprpl89_* in the Blank3D vendored copy to avoid collision with shotpumpkin89's unrelated sp89_* ABI.
- No ChatGPT-generated image asset is used by this change.

Host adapter policy
-------------------
- Image registry capacity: 128.
- Dynamic image IDs: 20000..32000.
- Current host max decoded dimensions: 1024x1024.
- Current host uploads the first decoded frame as a static texture. The full imgcc0 animated/multipage vendor remains intact; animation playback is not wired into this adapter yet.
